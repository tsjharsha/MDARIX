# Build history (archive)

These documents record how MDARIX R1 was built between 2026-09-16 and
2026-09-29. They are kept for traceability, **not** as a description of the
current system. Several of them contradict each other or were superseded later
(for example, GO/NO-GO verdicts changed repeatedly and some "complete" reports
still list open items). For the current state, see [../../STATUS.md](../../STATUS.md).

| Folder | Contents |
|---|---|
| [day-reports/](day-reports/) | Day 0–35 implementation and validation reports, Week 1/Week 2 reviews, Part 3/Part 08 reports, manual UI checklists |
| [stage-reports/](stage-reports/) | Future-architecture, Stage 1–4, Mapping Studio, Admin and Package 1–5 status reports |
| [release-decisions/](release-decisions/) | MVP GO/NO-GO decisions, release readiness and blocker evidence |
| [reviews/](reviews/) | Week 1 review findings and matrices |
| [validation/](validation/) | Day 20–23 era access-control, auth, integration, entitlement, signature and release-assurance validation |

Code, file and route names mentioned in these reports reflect the repository at
the time they were written (for example `day14_router.py`, now
`backend/app/unknowns_failure_chain_router.py`, and `day0_db_test.py`, now
`scripts/check_database_connection.py`).
