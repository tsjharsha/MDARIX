# Roles, permissions and personas

Platform Admin controls customers, plans, configuration, integrations, security and audit. Customer Admin controls only its tenant’s users, roles, mappings, integrations and configuration within entitlements. Quality Investigator works assigned investigations and evidence; Regulatory Approver performs governed human decisions.

Authorization is server authoritative. UI visibility is advisory and must not be used as a security boundary. Deny wins, protected fields remain protected, and support access must be scoped, approved, reasoned and expiring.
