# New developer first week

1. Read the index, status, architecture and limitations documents.
2. Start only the local Compose services required for the task.
3. Confirm database identity and apply migrations in a disposable environment.
4. Run focused tests before the full suite.
5. Trace one authenticated request from route through authorization, service, persistence, audit and response.
6. Test Tenant A/Tenant B negative access before changing tenant-scoped code.
7. Keep evidence and update status classifications truthfully.
