# Ask MDARIX

Ask MDARIX accepts investigation-context questions and returns structured known facts, evidence, contradictions, unknowns, gaps, limitations, provenance and human-review status. Provider abstraction supports Groq/Ollama where configured and deterministic fallback on outage.

The authoritative context builder must remain tenant-filtered, field-policy filtered, temporal and provenance-aware. Connectivity alone is not proof of grounded output.
