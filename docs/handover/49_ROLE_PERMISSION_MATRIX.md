# Role and permission matrix

| Persona | Scope | Typical authority |
|---|---|---|
| Platform Admin | Platform/control plane | Customers, tenants, plans, configuration, operations, security and audit |
| Customer Admin | One tenant | Users, roles, mappings, integrations, security and tenant audit |
| Quality Investigator | Assigned tenant records | Investigations, evidence, hypotheses and review preparation |
| Regulatory Approver | Authorized tenant records | Governed human approval/rejection and signatures |

The API remains authoritative; role labels or hidden navigation never grant access.
