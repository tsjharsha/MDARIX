# Open questions and handover risks

- Which deployment target, PostgreSQL certificates, runtime secret manager and alert destination are approved?
- Which design partners will provide endpoint contracts and test credentials?
- Which regulatory sources and licensing permit ingestion/citation?
- Which MFA/SSO provider is required for pilot?
- Which evidence and retention policy is contractually required?
- Which browser and screen-reader evidence set is required for sign-off?

Until answered, production and compliance claims must remain qualified.
