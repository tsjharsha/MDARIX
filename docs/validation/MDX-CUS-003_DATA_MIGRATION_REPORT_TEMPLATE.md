## 1. Purpose and scope

This report shows that the records your migration plan put in scope arrived in MDARIX complete and correct, or
states what did not and why. It covers every import run of the plan [plan reference and version].

## 2. Rules

- **MRP-R01** Every count in this report shall be copied from the run's data-quality report in MDARIX, never typed
  from memory. The run report is in the "Data-quality reports" panel of the Import screen
  (`frontend/src/features/workspace/sections/ImportReports.tsx:188`), or `GET /api/v1/data/import/runs/{import_ref}`
  (`backend/app/data_import_router.py:473-494`).
- **MRP-R02** For each source, the source count shall equal rows read plus rows excluded at cleansing (MDX-CUS-002
  section 4).
- **MRP-R03** For each run, rows read shall equal rows accepted plus rows set aside; the run report says so in
  "balanced" (`backend/app/trial/imports.py:2073-2109`).
- **MRP-R04** Every harm-suggesting row shall be listed in section 5 with its triage outcome.
- **MRP-R05** No row shall remain set aside without a decision at the date of this report.
- **MRP-R06** Every difference found in the sample of section 6 shall be a deviation with an outcome.
- **MRP-R07** The report shall conclude in one of two ways: "complete and correct as planned", or "not complete or
  not correct", with the open items listed.
